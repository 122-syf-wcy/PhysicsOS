# PhysicsOS 官网 · 本地设计预览

2026-11-07 第一版可点击设计样稿。薄荷绿 / 奶白 / 冰蓝，玻璃球与半透明卡片，采用新生成的薄荷色液态玻璃星球 IP。仅新增此目录，不连接生产数据，不部署服务器。

## 查看

在仓库根目录运行：

```sh
node demos/official-site/server.mjs
```

- 官网预览：<http://127.0.0.1:3096>
- 内容配置：<http://127.0.0.1:3096/admin.html>
- 使用系统现有 Node，无需安装依赖。端口可以通过 `PHYSICSOS_SITE_PREVIEW_PORT` 调整；仅监听本机。

## 设计与交互

- 首屏：公益定位、玻璃 IP、分层文字入场、指针视差、缓慢运行的玻璃星轨与漂浮卡片；正式产品入口指向 `https://physics.dongsiwei.com`。
- 功能展示：波、磁场、抛物线三个参数可调的概念动画，支持暂停。这些为官网交互小样，不调用正式物理引擎。
- 用户声音：反馈轮播，可切换 / 暂停；悬停、焦点停留及系统减少动态偏好下停止自动切换。
- 共创项目：姓名、身份、项目名称、介绍、头像、链接和卡片颜色。
- 建议弹窗：分类、文字、联系方式、图片选择 / 拖入 / 缩略预览 / 移除；最多 3 张、单张 5 MB，支持 PNG、JPEG、WebP、GIF；校验实际图片可解码。
- 内容工作台：反馈和项目均支持编辑、增删、排序、保存、恢复示例；每类 1–12 张。
- 交互动效：滚动分层展开、吸附导航与阅读进度、实验标签的玻璃滑块、按钮微吸附和扫光、贡献卡片倾斜与追光、弹窗轻盈展开。
- 左下角可切换动效 / 静谧模式；遵循系统减少动态效果，入场只播放一次，暂停后仍可正常反馈与上传截图。
- 响应式桌面 / 平板 / 手机布局，原生 dialog、键盘标签切换与焦点返回。
- 动画按需计算：首屏与实验离屏、页面隐藏或暂停时停止 JS 动画帧调度。

## 本地数据边界

- 所有初始评价和贡献项目均为清楚标记的设计样例，不代表真实评价或贡献者。
- 内容配置保存在当前浏览器 `localStorage`，键为 `physicsos-website-content-v1`。
- 提交的演示反馈与图片保存在当前浏览器 IndexedDB `physicsos-website-preview` / `feedback`，界面明确告知没有发送给平台。
- 本地预览不包含登录、服务端内容管理、审核、公开反馈接口或真实文件上传。
- 不同浏览器不共享本地数据。开发者工具中删除上述数据库 / 存储键即可清除本地演示数据。
