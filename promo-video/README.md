本目录保存多轮宣传片的源代码、分镜、剪辑参数、字幕、素材清单和生成/采集脚本，不表示每轮产物都已验证或适合直接发布。

- [音乐视觉片](mv/)与[90秒素材包源工程](xiaoyunque-90s-v1/)。

## 本次版本化范围

提交源码、脚本、文案、JSON 配置、字幕、许可证和素材来源说明。不提交视频成片、音频、逐帧截图、生成图像、字体二进制、PDF、压缩交付包或本机 agent 状态。

因此，clone 后不能假定已经具备渲染所需的全部媒体。先按对应工程的素材清单准备有权使用的输入；没有素材时应明确报缺失，不把空白画面或静音当作完整输出。不要把本机私有素材直接发布到公开仓库。

采集、语音或图像生成使用既有环境变量/受保护文件中的凭据。环境文件和会话 Cookie 不提交，不将生产账号信息写入脚本或录制文件。本次源码同步没有执行采集、生成、渲染或对外发布。

部分历史脚本保留当时的路径与工具依赖，移到其他机器前需要核对；它们不是安卓应用的构建前置，也不证明安卓或正式 Web 已完成验收。
