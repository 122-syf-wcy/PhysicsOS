# 最终融合剪辑操作单

## 推荐剪辑顺序

1. 建立 **1920×1080、30 fps、90 秒** 时间线。2K/4K可后续按真实素材能力交付，不把小尺寸生图强行称为原生4K。
2. 先导入主 BGM 候选，测实际拍点；按 16 秒揭幕、72 秒第二次展开、84 秒收尾放目标标记。音乐未生成前只使用这几个创作标记，不声称已经精准对拍。
3. 按 timeline.json / timeline.csv 放入 16 个镜头块；把每个故事关键帧先作为占位，组成可审的 90 秒结构。
4. 用逐镜提示词在小云雀生成 5 段人物/空屏底片，逐段替换关键帧。每段生成略长于目标的版本，留剪辑余量；不要把全片一次性交给模型生成。
5. 产品功能段直接用真实截图与 H02 实录。AI 不画 UI；截图后期缩放不是伪造新功能。
6. 加入独立旁白，再放字幕。voiceover.srt 是文本时间草案，需要按实际配音校准。
7. 最后才加音效、侧链与总响度；不要一边改脚本一边把声音做死。

## 图层建议

- V1：AI 场景底片 / 官网或产品真实画面。
- V2：需要时的真实界面合成与裁切。合成不稳就直接切真实界面，不强求屏幕替换。
- V3：真实 logo；不让生图或视频模型重画。
- V4：每镜一句短标题/CTA。
- V5：旁白字幕与必要的历史示例说明。
- A1：旁白。
- A2：唯一主 BGM（或同一配乐的分轨）。
- A3：独立音效。
- AI 视频自带音轨一律静音，避免每镜换一套音乐/环境声。

## 可读性与构图

- 1080p 主标题可从 72–100 px 起，短字幕从 38–48 px 起，再以实际成片手机预览判断；不要把整页 UI 当小字墙。
- 核心字幕一行约 12–18 个汉字，最多两行；旁白较长可分两次显示。
- 使用本包 Noto Sans SC 字体，许可证随字体保存。英文字号注意 PhysicsOS 中大小写。
- 主体留在画面中间约 80% 区域。重要按钮、实验读数、字幕不得被 IP、光效或光标挡住。
- 真实 UI 不拉伸比例。非 16:9 原生裁切可以完整适配并留白，或再裁到一个清晰局部；不为了铺满屏幕把字拉扁。
- K02/K05 的空屏是合成位，不保证视频生成后四角完全稳定。优先平直单应变换；若模型扭曲屏幕，换用稳定镜头或直接切全屏真实 UI。
- K02 角色接近屏幕右缘，避免把关键产品文字放在那一带。
- 官网保留当前薄荷/奶油白；产品保留自己的真实主题。不对 UI 做强烈风格滤镜、调色或换肤。

## 转场

- 以干净切镜、轻微同形匹配、少量 6–10 帧遮挡过渡为主。
- 16 秒产品亮相用明确强拍切，前面 0.25 秒声音吸气；不要长溶解削弱冲击。
- 不用十几种模板转场，不用爆闪、廉价粒子或过强镜头光斑。
- 角色镜头可用缓慢 3–5% 推进；真正会动的产品录屏不再叠大幅晃镜。
- 静态 UI 不做假点击响应。可以展示一个按钮，但没有录下真实效果就不要接一个 AI 捏造的成功状态。

## 历史示例标识

H 系列并非本次新拍；建议在相关功能段片角显示「历史功能示例，界面以当前版本为准」。源文件修改时间不等于准确拍摄时间，不能写成本次当天现场录屏。

AI 磁场回答 H05 与斜面校验 H06 是不同例题；S10 切入前给出清楚的示例切换，不做“磁场答案触发斜面验证”的假过程。S10→S11 可以连续，因为二者来自同一道斜面题。

## 正式发布前必须检查

- [ ] 每一个人和产品 IP 都是 Q 版可爱卡通，服装、帽子、眼镜、猫条纹一致。
- [ ] AI 镜头不含乱字、假按钮、假物理图像、多手指/多肢体、角色突然换脸。
- [ ] 功能画面来源清楚：本次官网 / 历史产品 / AI 故事底片，不混为同一类证据。
- [ ] 第一产品亮相与音乐瞬态落在实际同一帧，第二次高潮不是单纯加大音量。
- [ ] 旁白清晰；手机外放不失真；没有三段 AI 视频的随机背景乐叠在主 BGM 上。
- [ ] 出卷仍表现为草稿、检查和教师把关，不保证无需审核。
- [ ] 没有凭据、账号、学校/学生资料、私人对话或未经授权的试卷内容。
- [ ] 不出现“永久免费”“100%正确”“提升XX%成绩/效率”等未经验证承诺。
- [ ] 最后 4 秒以上可看清主网址 physicsos.dongsiwei.com。
- [ ] 音乐、音效、AI素材的发布/商业使用许可已确认并保存。

## 导出建议

主片先交 1080p、H.264 MP4、30fps、AAC 48kHz 立体声，高质量 VBR；按平台建议选择码率。另留一份无字幕/无音乐的干净版，方便后续改配音和画幅。片长与最后一帧以导出文件实测，不仅看时间线。

如要竖版，不把横版直接中心裁切：实验读数、教师与 IP 位于不同位置，需要单独重排。用户本次确认的主交付是横版，不把未制作竖版说成已完成。
