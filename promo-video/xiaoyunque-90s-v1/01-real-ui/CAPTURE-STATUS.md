# 真实画面来源与缺口

## 本次已成功

通过既有服务器网络访问正式官网 https://physicsos.dongsiwei.com/，获得 5 张真实高清截图。见 website-capture.json：浏览器视口 1920×1080、DPR 2，部分按网页原生分区裁切。内容包括当前薄荷绿/奶油白首屏、互动小样、AI/题目到实验功能介绍、结尾与整页。不是本地预览，不是 AI UI。

服务器访问两个正式域名均返回 HTTP 200；这不等于每个交互页面都完成了本次截图验收。

本次认证使用既有所有者管理的凭据在内存中建立临时会话，未输出或保存密码/Cookie、未保存浏览器状态。认证本身会建立会话，但没有创建/删除实验、提交 AI 请求、生成试卷或修改线上配置。

## 本次交付的产品素材

H 系列来自仓库既有生产截图/录屏流水线输出，本次逐张检查并裁去账号、侧栏最近空间与历史对话等信息。只做原像素矩形裁切，不重绘 UI，不新增验证徽章，不替换待检查状态。

- H01、H03：同一平抛实验的起始/末状态。
- H02：历史 CDP 录屏帧按原始时间戳还原，8.9 秒、1080p/30fps、无音轨。原 UI 为 0.25x 回放，不代表 AI 生成速度。
- H04：历史真实实验选择页。
- H05：历史磁场概念 AI 回答局部，不声称另一个实验生成任务成功。
- H06 / H06a / H06b：同一道历史斜面题的原生验证卡与对应场景，不能与 H05 拼成同一道题。
- H07：历史试卷准备页，原生待生成/待检查状态保留。
- H08：历史产品首页功能区。
- H09：历史资源库正文，去掉容易过期的顶部数量。

历史素材的精确原拍摄时间没有全部独立核实；清单记录原文件修改时间，明确不把它当作精确捕获时间。原 UI 与当前正式版本可能不同。正式发布时可保留「历史功能示例，界面以当前版本为准」小字，或在授权演示账号中补拍最新材料后替换。

H06 源图分辨率比其余近期截图低，适合局部特写，不做“原生 4K”宣传。所有源文件、裁切坐标与处理见 historical-assets.json。
