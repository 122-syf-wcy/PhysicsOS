# PhysicsOS《让物理，被看见》90 秒导演分镜 v1

**用户已确认：90 秒 / 16:9 横版 / 面向物理教师 / 全员 Q 版可爱卡通 / 完整教师工作流 / 小云雀生成故事镜头，最终由用户剪辑。**

## 先看这条主线

**一个备课中的“怎样讲清楚” → 好奇心搭子出现 → 16 秒产品正式亮相 → 实验可视化 → AI 辅助分析与可见校验 → 备课出卷与教师审核 → 回到课堂与品牌。**

不是功能堆砌，也不是“数字人站着念广告”。可爱来自角色，震撼来自留白、尺度对比、真实产品和声音结构。

### 图像角色

- **教师 A**：原创 Q 版物理教师，栗色短发、圆眼镜、奶白针织衫、灰蓝外套、深蓝裤、白鞋。
- **产品 IP B**：已有小物理老师的 Q 版适配，米色贴布帽、黑色卷长发、淡黄 T 恤、棕短裤、米白鞋；灰白虎斑猫始终为同一只。
- **官网 IP C**：当前官网的薄荷玻璃星球。出现在官网实拍与可选短片；不和产品内老师角色混名，不宣称 C01/C04 是新的官方定版。
- 全部是虚构卡通角色；不冒充真实教师、学生或用户证言。人物不做口型，旁白独立录制。

### 真实素材使用规则

- `W` = 本次拍摄的正式官网真实画面。官网演示小样不当作登录产品引擎运行证据。
- 本次独立产品捕获在只读保护下停在启动遮罩，**没有产出新的产品功能截图**；没有降低保护、创建实验或发起 AI 任务。v1 不使用不存在的 `P` 素材。
- `H` = 已存在、经过本次查看和隐私裁切的历史正式产品画面/录屏。**标注历史示例；原文件修改时间见清单，不等同已核实的精确拍摄时间。不是本次新录，更不是未发布设计稿。**
- `K` = 生图模型生成的故事关键帧；空白电脑/舞台屏幕为后期合成位，不是产品功能。
- `B` = 原产品 logo、字体等品牌文件。
- 产品镜头明确使用清单中的 H 系列历史真实素材；若正式发布前要展示最新状态，应在授权演示账号中补录后再替换，不让小云雀补画缺失界面。

## 音乐与镜头网格

创作目标 **120 BPM、4/4，45 小节 = 90 秒**。每拍 0.5 秒，每小节 2 秒。以下是**创作/剪辑目标，不是对已生成音乐实测的节拍结果**。有真实音频后，先测 BPM 与第一强拍，再微调剪点。

- **16.000 s**：第一强拍，产品首次完整亮相。
- **15.750–16.000 s**：目标 0.25 秒吸气留白；不要让音乐生成器随意填满。
- **42.000 s**：鼓组收窄，为 AI 解释让出听感。
- **60.000 s**：教师出卷工作流进入第二次递进。
- **72.000 s**：第二次、也是最终最大情绪展开，回到课堂价值。
- **84.000 s**：鼓组退出，品牌和网址清晰落下。
