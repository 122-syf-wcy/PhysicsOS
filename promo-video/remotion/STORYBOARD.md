# PhysicsOS 宣传片 v3 · 浅色产品片（Remotion）

- 成片：`out/v3/physicsos-promo.mp4`（1920×1080 · 30fps · 78 秒 · H.264 + AAC）；v1、v2 保留在 `out/v1/`、`out/v2/`
- 方法：GitHub 上的两个视频技能，已装进项目 `.claude/skills/`（`.claude/` 不入库）
  - [remotion-dev/skills](https://github.com/remotion-dev/skills)（Remotion 官方）：先有旁白音频再定画面长度、音频/音效、转场
  - [Rieranthony/product-film-skill](https://github.com/Rieranthony/product-film-skill)（MIT）：测拍 → 按小节剪曲 → 节拍表驱动画面；大字逐词落版、magic move、光标点击、相机推近、音效对峰值；`src/kit/`、`scripts/product-film/` 取自该技能
- 配乐：Mixkit「Dreaming Big」（Ahjay Stelino，Mixkit Stock Music Free License），135 BPM，按小节剪成 44 小节：安静前奏 → 渐强 → 第 30 小节抬升落在资源库 → 第 38 小节回落托住口号 → 原曲收尾
- 旁白：小米 MiMo TTS。音色先用 `mimo-v2.5-tts-voicedesign` 按「二十多岁的年轻女老师，清亮温柔、像和学生聊天」生成参考，再用 `mimo-v2.5-tts-voiceclone` 合成全部 12 句，保证同一个声音；语气提示「自然、不要播音腔」；响度 -16 LUFS，配乐单独约 -18、旁白时约 -28 LUFS
- 插画：gpt-image-2.5-sunburst，以启动页封面为参考图：K1 教室、K3 物理从课本里飞出来、K2 走廊；角色半身/全身像 3 张（抠图）

## 文件与命令

```
src/cues.ts             节拍表：镜头小节数、旁白起点、每个动作对齐的短语
src/scenes.tsx          9 个镜头      src/ui.tsx   水彩底/光束/窗口相机/字幕/标题/角色
src/Promo.tsx           转场、混音、音效
src/voiceover.json      旁白文案、模型与参考音色、语气提示
src/voiceover-timing.json  每句短语起点（scripts/vo-timing.mjs 生成）
src/music-edit.json     曲子按小节剪辑方案
scripts/voiceover.mjs   MiMo 合成（逐句串行、限流重试、超长自动重来）+ 响度归一
scripts/cutout.py       角色抠图   scripts/gen-keyframes.mjs  插画生图
```

```bash
cd promo-video/remotion
npm run studio                                   # Remotion Studio 预览
npm run vo && node scripts/vo-timing.mjs         # 改文案后重做旁白并重新对齐
npm run render                                   # 出片 → out/v3/physicsos-promo.mp4
```
