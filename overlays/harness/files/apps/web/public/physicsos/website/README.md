# PhysicsOS 正式官网

复用已确认的 `demos/official-site` 液态玻璃设计，官网静态资源由 Harness overlay 发布。只包含正式页面、交互代码、样式、优化后的标志与星球 IP，不发布本地管理原型、原始素材或验收截图。

## 入口与数据

- 官网资源路径：`/physicsos/website/index.html`。所有静态资源使用 `/physicsos/website/` 绝对路径，支持服务器将根入口映射到本页。
- 官网：`https://physicsos.dongsiwei.com/`。系统与管理员入口：`https://physics.dongsiwei.com/`。管理员登录后在现有后台的「内容 / 官网管理」管理发布内容和反馈。
- 官网根入口保留旧实验、贡献和密码重置 hash 链接，页面加载前跳转至系统域名根路径并保留原查询串与 hash；官网自身锚点和其他 hash 不跳转。系统根路径直接加载应用，旧 `/app` 链接由反代兼容跳回根路径。
- 展示配置：`GET /physicsos/notice/public/website`，只读服务端公开配置；初始数组为空。初次加载、无已发布内容和加载失败分别显示清楚的状态，失败可以重试；页面重新获得焦点时刷新公开内容。
- 提交反馈：`POST /physicsos/notice/public/website-feedback`，携带分类、正文、可选联系方式、当前路径和真实图片 base64。服务器返回有效 `id` 与 `createdAt` 后才显示成功回执；失败保留表单及选中的图片。
- 截图支持 PNG、JPEG、WebP、GIF，最多 3 张，单张不超过 5 MiB；浏览器先检查类型、大小及是否可解码，服务端仍是最终校验与持久化边界。
- 内容及反馈不写入浏览器持久化存储。关闭标签页前未发送的反馈仅留在内存；动效偏好单独使用 `physicsos-website-motion`。
- 展示字段通过文本节点渲染；链接和头像仅允许无凭据的完整 HTTP(S) 地址，颜色必须为 6 位十六进制值。公开 DTO 不包含联系方式、原始反馈图片或来源反馈 ID。

## 动效与可访问性

保留分层入场、星轨画布、指针视差、玻璃卡片、实验标签和反馈轮播。静谧模式与系统减少动态效果不隐藏正文或弹窗；页面隐藏或相应画布离屏时停止帧循环。异步发布内容仍注册滚动展示。轮播兼容 0 / 1 / 2 / 12 条，悬停、焦点停留与页面隐藏时暂停自动切换。

交互实验是物理概念动画，完整产品实验通过系统域名进入。图片反馈仅管理员可见，不自动发布为公开评价。官网域名只代理官网静态文件及两个公开接口，不提供后台接口或私密截图。

## 验证

遵循根目录 `AGENTS.md`：所有构建、测试与正式验收在服务器 `107.151.246.59` 的 Docker 环境完成，不启动本机测试或浏览器服务。

独立接口/编码测试（Node 20+，无额外依赖）：

```sh
node --test scripts/website/*.spec.mjs
```

候选页面浏览器验收需要覆盖：

1. 两个域名根入口、上述静态路径和旧 `/app` 跳转；页内锚点、产品深链接、原有 API 及管理员登录保持可用。
2. 公开配置为 0 / 1 / 2 / 12 条时轮播、分页与布局；没有发布内容时不出现示例评价和贡献者。
3. 管理员发布、排序与下架后，官网重新获得焦点或刷新即显示当前配置。
4. 暂时断网或公开 GET 失败时出现重试提示；重试成功恢复正常展示。
5. 提交带真实 PNG 截图的反馈，管理员可在收件箱查看；失败响应与断网时不显示成功，草稿及图片仍保留。
6. 360 / 390 / 768 / 1024 / 1440 px 无横向溢出；键盘导航、弹窗 Escape、分类、图片移除与焦点返回正常。
7. 正常动效、静谧模式、系统减少动态与标签页隐藏；异步加载贡献卡片后仍可见，暂停状态下上传与成功反馈可见。
