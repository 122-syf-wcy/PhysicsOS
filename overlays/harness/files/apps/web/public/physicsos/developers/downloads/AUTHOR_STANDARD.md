# 作者与 GitHub

把作品署名展示清楚，同时保留共同贡献和素材来源。

## 每份作品都有明确作者

| 字段 | 说明 |
| --- | --- |
| 显示名称 | 公开署名；与登录账号绑定 |
| 简介 | 简短介绍与贡献范围，不发布联系方式或私人资料 |
| GitHub 个人主页 | 用于展示个人链接与对应头像 |
| 源码仓库 | 单独填写；仓库组织不一定等于作者 |
| 头像上传 | 未提供 GitHub 时使用上传图片 |
| 共同作者 | 列出姓名、链接、分工与授权 |

## 头像显示优先级

- 提供 GitHub 个人主页 → 自动显示对应 GitHub 头像。
- 未提供 GitHub → 使用上传头像。
- 没有头像或加载失败 → 使用姓名缩写。

GitHub 头像应缓存并统一裁切尺寸。链接仅代表填写了该地址，不代表身份已认证；完成 GitHub 绑定后才能出现认证标识。服务端仅通过受控 GitHub 接口获取资料，不能抓取任意头像 URL。

## 署名与版本一起发布

实验顶部展示当前默认版本主要作者，底部展示共同作者、仓库、许可证和版本。新作品审核通过后，默认效果与作者同时更新。既有作者的贡献历史和第三方素材署名仍保留。

> **许可不是装饰字段**：自有代码与文档遵循仓库 Apache-2.0 规则。第三方模型、纹理和图片分别记录许可证、来源与是否修改；不把不兼容素材一并宣称为 Apache-2.0。
