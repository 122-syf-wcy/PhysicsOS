# 三维与交互

统一生命周期、输入方式与性能边界，实验才能长期稳定运行。

## 四个清楚的生命周期

| 阶段 | 责任 |
| --- | --- |
| mount | 创建相机、renderer、controls、装置与监听；绑定资源所有权 |
| update | 消费已有快照，更新变换、读数、显示状态；不重建整页 |
| resize | 同步画布、相机和分辨率，不重置实验条件 |
| dispose | 取消 RAF，移除监听/Observer，释放控件与自有 GPU 资源 |

> **模板中的真实入口**：src/main.ts 调用 connectExperiment 与 mountLens，后者返回 update/dispose；ResizeObserver 处理尺寸。这里的代码随模板一起交付，不依赖一个不存在的 npm SDK。

## 直接操作，也能精确操作

- 统一三维入口，无二维切换；视角归位与复位实验分开。
- 拖动器材时锁定相机；拖动空白才旋转，滚动/双指按约定缩放。
- 同一参数支持拖动、数值输入与键盘；触摸目标至少 44 CSS px。
- 标签避让器材与彼此，超出视野时保留真实读数，不把离屏物体硬贴到边界。
- 加载失败与 context loss 提供重试和状态说明，保留已提交条件与记录。

## 建议的首版验收预算

| 项目 | 首版目标（需真机记录） |
| --- | --- |
| 像素比 | 默认 DPR ≤ 1.5，按设备降低 |
| 静态实验 | 只在条件、视角或尺寸变化时绘制 |
| 动态实验 | 使用平台时钟；后台暂停；不每帧重渲染整页 |
| 手机 | 目标设备持续交互 ≥ 30fps；记录设备、浏览器、采样时段 |
| 资源 | 压缩模型与纹理；按实验加载；提交压缩体积与显存统计 |
| 销毁 | 连续进入/退出至少 10 次，无持续增长的 listener / renderer / GPU 资源 |

这些是规范目标，不是当前全部实验已经达到的指标。性能优化不能牺牲物理精度。大场景的预算需在评审中给出理由。
