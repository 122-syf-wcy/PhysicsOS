# Warm Lab 视觉规范

同一间温暖、安静的实验室，容纳不同开发者的好作品。

## 统一的是系统，不是每个像素

采用已选定的暖色拟真实验台：暖白底色、自然木质或领域适配背景、柔和光照、可信器材和灰绿色控件。装置占据主视野，页面保持清楚的层次与留白。

| 层级 | 要求 |
| --- | --- |
| 页面 | 标题与目标 → 实验台与参数 → 关键读数 → 探究条件 → 记录与作者 |
| 控件 | 复用共享按钮、输入、滑杆、图层、错误与加载状态 |
| 场景 | 桌面装置可用木桌；波动/天体等使用适合背景，仍遵循同一色彩与材质规则 |
| 标注 | 物理语义色固定，数值始终来自快照；单位与可读性优先 |
| 手机 | 先装置后参数；无页面横向溢出；控件不压住器材 |

## 主题基准值

### 候选主题 token · 接入时映射到平台语义 token

```css
:root {
  --lab-bg: #fafaf7;
  --lab-surface: #fffdf9;
  --lab-text: #2e3d38;
  --lab-muted: #687369;
  --lab-accent: #567d70;
  --lab-border: #e5e6df;
  --lab-radius: 10px;
}
```

这是新的 Warm Lab 基准，尚未替换全站主题。贡献实现不得用全局 :root 覆盖宿主；由共享主题容器提供 token。细小文字不使用过浅灰，键盘焦点和状态对比度必须清楚。

## 素材服务于物理表达

- 模型用 GLB/glTF，纹理优先压缩并注明来源。
- 生图可用于环境、贴图和封面；不能把动态读数、光路、坐标或公式烘焙进图片。
- 玻璃、金属、塑料的材质要可信，但不堆叠发光、后处理和昂贵反射。
- 光屏模糊等非完整物理模拟，注明教学示意，不假称波动光学求解。
- 外部素材保留作者、许可证与修改记录，不能只提供一条“网络图片”来源。
