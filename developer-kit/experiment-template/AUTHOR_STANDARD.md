# 作者与 GitHub

把作品署名展示清楚，同时保留共同贡献和素材来源。

## 每份作品都有明确作者

| 字段 | 说明 |
| --- | --- |
| 显示名称 | 公开署名；与登录账号绑定 |
| 简介 | 简短介绍与贡献范围，不发布联系方式或私人资料 |
| GitHub 个人主页 | 用于展示个人链接与对应头像 |
| 源码仓库 | 首版写入包内 README；专用资料字段后续开放 |
| 头像上传 | 未提供 GitHub 时使用上传图片 |
| 共同作者 | 首版写入包内 README 与素材授权文件，保留姓名、分工与许可 |

## 头像显示优先级

- 提供 GitHub 个人主页 → 自动显示对应 GitHub 头像。
- 未提供 GitHub → 使用上传头像。
- 没有头像或加载失败 → 使用姓名缩写。

首版直接显示 GitHub 头像，加载失败显示姓名缩写；专用缓存后续完善。链接不表示已验证账号归属。未填 GitHub 可上传不超过 256 KiB 的 PNG、JPEG、WebP；不接受任意远程头像地址。

## 署名与版本一起发布

实验页显示当前版本的主要作者、头像、GitHub 与版本；完整的共同署名、源码和许可保留在包内审核资料中。新作品审核通过后，默认效果与作者同时更新。既有作者的贡献历史和第三方素材署名仍保留。

> **许可不是装饰字段**：平台模板代码采用 Apache-2.0；贡献文件须明确代码许可与授权。第三方模型、纹理和图片分别记录许可证、来源与是否修改；不把不兼容素材一并宣称为 Apache-2.0。
