# 提交与审核

让代码、结果和作者一起被看见，也让每一次发布可追溯。

## 投稿流程只围绕实验文件

- 在独立模板里完成开发与预览。
- 运行 npm run release（完整检查、清理构建、验证与打包）。
- 在凸透镜实验页选择“贡献实验”，提交生成的 ZIP、作者资料和版本说明。
- 自动检查通过后进入后台审核，可退回修改。
- 管理员通过后自动发布，新进入该实验的用户看到最新效果与作者。

### 贡献者实际运行的命令

```shell
npm run release
# 产物：release/convex-lens-1.0.0.zip
```

> **接入状态**：凸透镜的完整链路由本版本提供。任意登录账户可以投稿；只有平台管理员（SUPER_ADMIN）能够审核并发布全站默认版本，学校管理员无法替换全站内容。上传成功不等于已经上线。

## 审核后同步的是发布指针

### 平台负责的发布链路

```text
接收 ZIP → 隔离存储 → 解压校验 → 交互审核
  → 冻结文件与内容摘要
  → 更新对应 experimentId 的默认发布版本
  → 主站加载新入口与资源、展示该版本作者
```

最新审核通过版本直接替换默认效果；历史用于审计与回滚。更新不热替换正在运行的实验；审核退回或已确认回滚的发布失败保留上一版。若存储故障使提交结果不确定，平台暂停服务，恢复后请刷新版本列表确认实际结果。每个运行会话固定 releaseId 与 protocolVersion。

## 审核需要什么

| 检查面 | 材料 |
| --- | --- |
| 文件一致性 | 源码与编译入口、清单、可重建依赖和资源摘要 |
| 代码风格 | format、命名、lint、typecheck 结果 |
| 物理与交互 | 引擎接口、参考用例、拖动取消/提交和模型限制 |
| 三维稳定 | 移动端、重复加载、资源释放、WebGL 失败提示 |
| 作者与许可 | 当前作者、GitHub、共同署名与素材许可 |

平台管理员在选中的审核预览中下载冻结审核 ZIP，核对其中源码、dist、cases.json 和素材许可；显示的完整 SHA-256 与批准请求一致。GET /physicsos/experiments/packages/:id/archive 只允许作者或 SUPER_ADMIN 登录下载，已批准版本仍受此限制；响应为不缓存的惰性 ZIP 附件，公开资源继续只提供 dist。提交新版本不能跳过审核；上传成功只表示接收文件，不代表已经公开或替换线上效果。
