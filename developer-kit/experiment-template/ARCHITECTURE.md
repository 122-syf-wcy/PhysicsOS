# 目录与模块边界

把计算、呈现与交互拆开，给后来接手的人留出空间。

## 这是一个独立目录

| 文件 | 责任 |
| --- | --- |
| experiment.json | 目标实验、版本、入口、协议与依赖声明 |
| src/main.ts / protocol.ts | 初始化三维与校验宿主消息 |
| src/lens-renderer.ts | 根据只读快照显示器材，不引用平台源码 |
| public / dist | 静态入口与编译后的自包含浏览器文件 |
| preview / tools / tests | 本地宿主、构建校验打包、行为验证 |

## 每个模块只回答一个问题

| 模块 | 允许做 | 不允许做 |
| --- | --- | --- |
| 入口 | 创建实验视图区、连接宿主、声明清理 | 创建主站导航、登录或审核入口 |
| renderer | 把标准快照投影为三维装置 | 导入主站内部求解器或自行宣称物理校验 |
| interaction | 拾取与 preview/commit/cancel 意图 | 修改 parent.document、Cookie 或数据库 |
| assets | 本包资源加载与释放 | 运行时 CDN、跨包路径、远端代码 |
| 本地预览宿主 | 提供标明来源的开发快照 | 冒充已接入生产引擎或已完成审核 |

## 共享能力通过协议，不通过源码引用

参数面板、物理求解、记录、报告与作者由宿主管理。实验包只通过固定消息协议接收快照和发送操作意图，不 import @physicsos 内部包。平台以后如何重构，只要保持协议兼容，已审核实验文件就仍能加载。

> **协议状态**：协议 v1 已由模板预览器与凸透镜平台适配器共同实现。本地 source 为 preview-fixture；平台实际实验为 platform-engine，物理结果由现有光学引擎提供。
