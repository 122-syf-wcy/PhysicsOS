# 学生讲解表达小改动

用户明确要求：回答不展示引擎等内部信息，语气更自然、有趣。项目对象已确定为初高中物理学习者；当前截图把普通概念讲解展开为长表格和内部校验报告。

采用现有学生 persona 内的表达约束，覆盖实际 bundle preset 与 legacy preset：简单问答先给生活直觉、必要公式和关键点；计算/考试题才展开规范步骤。内部数值计算、物理数据校对及工具权限继续严格执行，对学生只呈现物理推理和可靠结果。

考虑过输出后关键词过滤，但它可能误删物理术语或破坏推导；单独引入风格配置和第二次改写也增加调用与维护。本次选择直接约束现有回答生成，不增加推理服务或用户设置。这是实现选择；没有把它记作用户另行选择或批准的方案。

实现与验证：只调整两份现有学生提示；后台分类 JSON 和实验代码协议不受自然语言规则影响。真实模型检查打招呼、牛顿第二定律概念、规范计算题和不安全请求，确认没有内部函数名/状态报告，保留必要公式、数值准确性及安全拒绝。
