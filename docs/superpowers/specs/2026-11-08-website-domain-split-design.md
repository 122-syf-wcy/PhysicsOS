# 官网与系统域名分离

用户要求：官网换独立域名，`physics.dongsiwei.com` 恢复原系统根路径，不要求用户使用 `/app`。用户已授权代理选择官网域名，选择 `physicsos.dongsiwei.com`，A 记录指向 `107.151.246.59`。

实现：取消 web-app 因官网文件存在而自动接管根路径。官网通过独立 Nginx vhost 映射 `/physicsos/website/index.html`，静态资源与两个公开 notice API 同源代理；系统管理接口只保留在系统域名。官网按钮、开发文档、历史链接指向系统绝对根地址。PWA 与密码重置恢复根路径；已生成 `/app` 链接在系统 Nginx 兼容重定向回根路径并保留查询串。

其他方案：仅 Nginx 把系统 `/` 内部映射为 `/app` 可临时恢复，但源码仍自动接管根路径；本次一并修复源码。官网独立静态服务可行，但新增复制发布和跨域接口成本，不采用。

部署必须核对远端 main、服务器源码、精确运行镜像；以当前镜像增量构建，仅更新 web-app、auth-host 和官网静态资源。在服务器隔离候选验证，保留旧镜像、配对数据库和应用数据恢复点。官网后台、截图、排序、上下架以及既有账号、实验、组卷和性能改动保持。

DNS 未生效时先完成候选和系统恢复，官网证书与公开 HTTPS 验证待真实解析后执行；不把未上线的网站报告为上线。
