# 对话题目代码实验

用户明确要求主对话调用子代理，按最新实验风格和提示词生成题目对应的实验代码，最终使用新的代码实验界面，完成后自行部署。无需用户再次选择实现方案。

采用专用代码生成工具/受限子代理和私有V3实验包。`physics_solve_question`产生通过引擎验证的完整场景后自动进入代码生成；可用专用工具重新生成已有场景。子代理只接收该题上下文、最新已发布开发说明与通用实验规范，输出受限renderer/CSS文件，不获得通用shell/文件/网页或进一步委派权限。工具生命周期、取消、深度、文件大小和重试均有边界。

物理场景、结果与题目条件由已有引擎保留；模板仅作为交付/风格基底，不以模板默认场景替换题目。验证并冻结生成代码，作为当前对话的私有artifact，独立于社区默认实验发布。事件只保存状态和不可变身份，预览URL按当前登录账号重新获取，支持重载/重启与权限隔离。

聊天卡片换为新代码实验播放器和交互面板，保留结构化解答与校验结果。实时代理场景不再自动跳到旧Lab。显式打开实验使用同一题目运行时和私有代码包。历史没有代码的对话显示生成入口，而不继续绘制旧模板；失败显示明确状态，可重新生成。

备选：仅换旧Canvas外观不足以满足代码生成；开放泛用子代理/文件工具增加不必要权限。因此采用受限内部编排、专门子代理组合和已验证的V3沙箱展示。所有构建、模型/浏览器验收与发布在107.151.246.59 Docker。保留main/服务器/镜像后续功能、旧镜像及数据恢复点，不泄露密钥/Cookie/完整环境。
