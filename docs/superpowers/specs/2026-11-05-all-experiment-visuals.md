用户已在接续会话明确要求按新模板制作所有实验，物理正确、简洁清爽、美观，完成后上传同步服务器部署，并授权自主处理，无需再次询问。

范围为 V3 注册表的 76 个实验、12 个领域。每个实验有独立、版本化 ZIP，通过既有上传、审核、默认指针流程发布。使用现有 V3 MessagePort 协议，物理事实只来自平台 snapshot.view / inspector / clock；几何投影、装置外观与标注由包承担。旧会话保持固定版本。

实现选择：使用自包含 Three.js 模块、程序化实验器材和共享轻量渲染基础层，按领域定制装置。保留每个实验独有的物体、光线、接线、场区、温度、波形和读数，不将冻结 SVG 渲染器包装为新三维作品。统一暖白背景、石墨文字、低饱和青绿器材与物理语义颜色，桌面与手机自适应。程序化几何本身比固定装置图片更适合准确跟随参数；已有许可素材仅在确有收益时使用。

相机操作只改变视角。世界坐标按统一比例映射，向量端点、轨迹、光线不重新求解或任意缩放。有限像、虚像、开路、零值、负方向、显示层开关均遵循快照。WebGL 不可用显示明确失败；不得偷偷显示旧官方模板冒充上传作品。绘制完成后再确认 frameId/revision。

构建与测试在 107.151.246.59 的 Docker 完成。本机用于编辑与 Git 整合。发布前核对 main、服务器 HEAD、运行镜像。服务端保留镜像和数据库/实验资源恢复点；使用标准 API 上传和审批，核验默认包 ID/SHA 与重新进入的页面。源码、报告、日志不得包含明文凭据。

验收覆盖所有 76 个包的元数据、依赖与实际 WebGL 首帧、领域关键物理几何、参数/时间变化、手机布局和无异常；对每个领域保存实际截图供人工审阅。只针对这批独立包发布；若无需宿主变更则保留正式镜像。
