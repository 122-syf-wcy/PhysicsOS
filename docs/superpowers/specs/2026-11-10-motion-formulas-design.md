# 实验卡片原理与公式

用户已确认将原理与公式加入实验自由画布卡片，与当前待发布功能一同上线，并要求计算结果随参数变化。现有专注编辑视图已有由物理引擎模型生成的 `workspace.derivation` 与 `DataPanelBody`，卡片尚未展示。

## 方案

复用已有推导数据与数学公式呈现组件，在实际实验卡片加入默认收起的「原理与公式」。继续保留专注编辑中的完整数据页。独立新增硬编码公式会造成参数与结果分离，调用模型生成解释则无法保证实时一致；此次选择现有确定性推导链。

平抛说明忽略空气阻力、水平匀速和竖直匀加速，展示位移、速度、落地时间和水平射程，以及当前参数代入。斜抛采用包含初始竖直速度的一般公式；最高高度包含距地面初始高度。结果读取引擎已有 `flightTime/range/maxHeight`。零重力不展示重力下落推导，也不将引擎播放时长当作落地时间。

只改卡片呈现、中文和英文标题、平抛/斜抛推导内容与对应测试。不改变实验状态、播放、参数控件、持久化、渲染器或其他运动求解。卡片折叠区限制高度并可滚动，公式仅在展开后挂载。构建与验证使用 107.151.246.59 现有 Docker 候选环境。
