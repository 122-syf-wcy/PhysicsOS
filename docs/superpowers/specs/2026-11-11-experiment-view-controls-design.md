# 实验视图与导航改进

接续「画布」会话最后三项明确要求：实验可放大和调整；加入工作台不遮挡实验和图表；项目、实验自由画布、教学画板使用不同的生图图标。

## 实现选择

- 在现有实验渲染器增加缩放、平移与复位，而非扩大整个页面或改变物理参数。保留旋转，支持滚轮、按钮、双指捏合；平移可用明确模式和右键/修饰键。用户视角在播放和尺寸变化时保留。
- 将加入工作台移入实验顶部动作区，桌面显示紧凑按钮，窄屏保留图标和无障碍标签。路由提示独立显示；加入工作台继续传递当前实验参数与版本信息。
- 三个图标沿用界面单色线条风格，分别表达文件夹、带节点的实验画布、带笔的教学板。通过用户指定服务及 gpt-image-2.6-sunburst 生成，产物压缩为静态资源并支持主题色。没有选择纯代码替代图标，因为用户明确要求生图。
