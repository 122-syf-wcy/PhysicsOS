# 实验文件贡献闭环

用户在 2026-11-03 明确选择接通“上传 ZIP → 管理员审核 → 对应实验自动展示”，以凸透镜作为第一个样板。本设计延续旧聊天已选定的独立路由、纯三维、Warm Lab、最新审核版默认和作者署名；不重新讨论架构。

## 目标与边界

贡献者从对应实验下载现有独立模板，开发、打包，上传 ZIP 和作者资料。服务器校验并冻结内容，平台管理员预览、通过或退回。通过后新打开的凸透镜实验加载该文件包，当前会话保留原版本。管理员可以回滚至此前通过的版本。

本次先接通 convex-lens / optics contract v1。其他实验继续使用既有实现，不能接受不兼容包后假装可运行。主站参数、物理引擎、测量记录、报告和账户权限继续由平台拥有；包仅承担隔离三维视图区。

## 已选方式与实现决定

此前比较过独立 HTML、平台独立路由、独立路由加三维；用户选择第三种并取消二维切换。文件投稿替代源码 PR 是用户后续明确纠正。本轮复用已有独立模板和实验页面分支，增加贡献宿主与 iframe 协议适配。

实现决定：平台级发布只允许 SUPER_ADMIN（学校管理员不能替换全站内容）；所有登录账号可投稿。首次未有社区版本时使用官方三维样板。WebGL 不可用显示解释与已有数据，不切回二维。

## 服务边界

- 新增 experiment-host，复用既有身份服务与 storage-domain；上传文件在独立目录持久化，不进入源码树或执行安装脚本。
- ZIP 20 MiB，解压总量 40 MiB，单文件 20 MiB，最多 1000 文件。支持普通 store/deflate ZIP，拒绝遍历、绝对路径、符号链接、重复路径、加密、损坏、超限、包外资源和不兼容清单。
- 上传产物为已编译静态文件；自动检查不声称代替物理或人工审查。审核绑定 ZIP SHA-256，预览与发布均读取同一不可变内容。
- 单个生产应用进程负责发布队列；发布失败保留原默认。服务端串行分配发布顺序，历史版本保持可读。
- 未审核文件仅作者及平台管理员可取得短期预览地址。公开资源只允许已审核包；服务只输出白名单内 dist 文件，不提供源码或目录列表。
- 所有实验 HTML 强制 CSP sandbox allow-scripts；iframe 不允许 same-origin/top-navigation/forms/popups。CSP 限制网络到当前包路径，禁止外部代码、Cookie/主站访问，开启 nosniff、无 Referrer 和无凭据 CORS。加载双方验证 source、origin、随机 channel，仅通过专属 MessagePort 交换公开实验状态和允许的参数意图。
- 资源域可配置为独立 origin；候选验证使用独立端口与隔离数据。正式发布前必须检查反代对 iframe 的 CSP/X-Frame-Options 不造成冲突，并记录资源隔离配置。

## 用户体验

凸透镜页“贡献实验”打开投稿与版本面板；显示模板、文档、ZIP、显示名、简介、GitHub 个人主页、可选头像和修改说明。GitHub 头像优先，链接不表示身份认证。用户能看自己提交的状态和退回理由。平台管理员额外看到审核队列、候选实际三维预览、摘要和通过/退回/回滚操作。

已发布作者、头像、版本随默认文件包展示。公开信息不暴露内部账号键、学校标识、存储路径或预览凭证。打开的实验固定 release id，页面不轮询替换正在操作的装置。

## 验收与环境

以 107.151.246.59 的隔离 Docker 构建测试。核对基线：origin/main 与服务器 /opt/physicsos HEAD 为 33023a2；运行镜像 sha256:45c40254bef05b8218c586a538c45f246a653da2a8ebdbe210c31455271b95b8。正式应用健康，候选不使用生产账户或数据。

验收必须真实经过 ZIP 上传、拒绝越权、审核预览、批准、打开实验加载对应包、参数通过正式物理引擎反映到包、第二版替换及旧会话保留、回滚、重启恢复、桌面与手机无溢出。发布前保留旧镜像和数据恢复点。
