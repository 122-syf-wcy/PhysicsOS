# 自由画布器材搭建

用户授权自行设计、实现并直接上线，无需提问或审批。

目标：学生在自由画布中直接选取器材、摆放、连接、修改参数并观察同一个电路的真实求解结果。当前卡片将器材库隐藏在专注编辑中，画布面积浪费，器材添加异步后不选中。

采用现有 CircuitDraft 与 WorkbenchInstanceRuntime，不增加第二份物理状态。搭建卡片直接显示分组器材库、选择器材属性、可拖放的电路区域、连接指引与撤销重做；从器材库拖入或点击添加，选择台上的器材联动属性面板，接线支持拖动和两次点击，提供端子断开操作。模板电路可以切换为器材搭建。新建搭建台及旧的小卡片使用足够的尺寸。保留快照、笔记、实验对照、权限和账户持久化。

方案比较：仅增加跳转专注编辑按钮无法解决画布内搭建；新增通用多物理约束求解器超出现有模型；采用已有电路拓扑编辑和真实引擎最适合本次交付。机械和光学模板继续使用它们支持的参数、物体位置操作，不把混放卡片称为跨领域物理耦合。

约束：恢复服务器未合入 main 的自由画布与后台实现；保持主线后续修复；只在 107.151.246.59 的 Docker 构建测试部署；候选镜像基于实际运行镜像；发布前保留镜像及成对数据恢复点；凭据不输出、不入库。

验证：卡片不打开弹窗即可添加、选中、旋转、删除、撤销；拖放坐标在外层缩放后正确；端子连接/断开影响真实读数；未接完的电路仍显示器材；场景和历史重载恢复；社区渲染器在搭建时不遮挡原生编辑；已上线画布同步与对照回归保持。
