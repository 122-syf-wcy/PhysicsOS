# 独立题目代码实验

用户对2026-11-04候选截图明确否定：旧平台图形加标注仍是旧样式，必须生成对应题目的独立实验可视化。用户已授权自主决定、完成后部署，无需再问。此前包装器方案不作为最终交付。

采用独立Canvas 2D（也允许浏览器原生SVG）renderer，模块不导入任何旧绘图代码；禁止仅reexport或调用renderPlatformFrame。主对话继续经现有专用子代理交付title/summary/rendererJs/stylesheet，平台引擎与V3快照仍是唯一物理事实来源。坐标投影、绘制材质和布局属于展示，禁止积分、二次求解或硬编码另一题的数值。

子代理获得完整原题scene、已验证答案、发布提示词正文、准确的SceneVisualModel/V3字段契约；不再获得旧renderer代码或要求生成SDK wrapper。为了生成完整独立画面，输出仍限制8192并尊重更低父预算，共享任务期限300秒，至多一次源码校验修复。现有模型off→none/native thinking与max_tokens兼容配置保留，主模型/high设置不变。

私有artifact记录追加可选rendererKind:'independent'，只有通过独立renderer约束的新创建记录获得该标记，旧记录不补写。封闭资源检查、冻结哈希、owner、签名和社区active指针的边界不变。新私有HTML使用仅承载作者画面的通用壳，隐藏旧模板标题/参数区域，保留严格SDK握手。基础字体/视口CSS独立冻结，作者CSS随后加载；原四个源码字符串保持不变。

聊天与私有Lab采用宽画面代码实验台，生成标题、玻璃工具栏、可展开条件/结果控件与源码入口。移除rev/engine等技术标签和狭窄旧参数侧栏。参数、播放、seek、恢复原题仍通过同一个平台runtime，不修改已验证题目或答案。没有independent标记的历史版本显示手动升级入口，不自动调用模型或展示旧图。

比较过继续旧renderer加CSS、独立Canvas、独立Three。用户已经拒绝第一种；默认Canvas能稳定服务现有二维物理快照、没有额外库或WebGL要求。Three不是本轮默认，不引入新的外部依赖。此为实现者自主选择。

最终门禁：旧renderer依赖、空包装器均被拒绝；真实父→子生成独立源码并绘制，画面与旧SVG图显著不同；t0/最高点/落地与参数改变读取真实engine frame；移动端布局与按钮；权限/重启/历史升级；服务器最终镜像、GitHub main、正式HTTPS及原76上传/审核/提示词功能。仅代码/协议通过或修好字体不能代表用户要求的效果通过。
