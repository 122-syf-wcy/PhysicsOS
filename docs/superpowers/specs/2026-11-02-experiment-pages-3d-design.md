# 独立实验页面与按需 3D

用户已选择方案三并授权直接实施。2026-11-02 补充确认：服务器以当前正式域名所在的 107.151.246.59 为准。

## 目标

所有 76 个实验取得可刷新、可前进后退的独立入口；首个完整样板为凸透镜成像，提供专属教学页面、直接拖动、二维光路、真正 Three.js 光具座、多次记录和共享报告/助教/自测。其他实验继续运行既有工作台，不宣称已完成 76 个定制页面。

## 实查与设计

线上与本地都已登录检查。当前光学实验使用通用三栏工作台，参数通过检查器操作，手机图像比例与标签可读性需改善。电路已有实物素材与操作，保留其引擎和功能。采用明亮的实验台、大面积装置视图、紧凑教学步骤、右侧参数和底部记录。手机先装置再控件，关键操作可达。

共享实验会话负责帧、播放、命令提交与场景持久化，页面只组织体验。3D 只读取 SceneVisualModel，不另算光学。Three.js 单独 optional factory 加载；失败与 WebGL context loss 可以返回二维，卸载完整释放资源。静态实验按需绘制，DPR 上限 1.5。

入口使用 /#/experiments/<template-id>，附带 scene 参数恢复当前账号的实例；共享链接只包含模板。现有 host 对任意路径返回 404 且通过根页面注入认证与资源路径，hash 路由可以保留完整宿主语义，无须修改生产反代或上游路由。未知入口返回实验选择器并给出可理解的提示。

凸透镜默认二维，用户切换后加载 3D；固定透镜，物体与光屏沿轨道拖动，同时可数值与键盘操作。拖动预览使用临时运行时，松手提交一次真实场景命令，取消恢复。五区快捷条件覆盖 3f、2f、1.5f、f、0.5f。u=f、虚像、超出轨道的像必须诚实展示。光屏模糊不冒充真实波动光学。

多次记录保存引擎快照中的参数与结果，附场景修订和时间。记录进入场景 metadata，沿既有账号场景同步保存；编辑物理条件不能覆盖已记录数据。报告在当前结果后附测量记录；CSV 复用现有序列化。题目来源、实验分支与恢复原题保留。

## 约束

- 源码在独立工作区 codex/experiment-pages-3d；保留原工作区所有改动。
- 本机编辑和 Git；服务器隔离 Docker 构建、测试，不占用生产应用写入租约。
- 不读取或输出明文密钥、Cookie、完整环境变量；凭据仅程序内部使用。
- 不全量重写求解器，不为所有实验强制加 3D。
- 发布前核对 main、检出和镜像，保留数据恢复点与旧镜像；本轮先提供验证好的候选供最终发布审阅。

## 验收

真实引擎五区数值；预览不污染修订和题目来源；取消/提交；2D/3D 同值；记录刷新与切换不丢；登录后恢复入口；后退和切换无循环；缺失实例不打开他人数据；3D 网络失败、context loss、反复挂载资源释放；桌面/390px 无横向溢出；原有实验和题目进入实验保持工作；可选包只在用户选择三维后请求。
