# 实验卡片原理与公式实施计划

实施方式：当前已隔离工作树中的原生实施；用户已确认卡片位置、参数联动与同次发布。

1. 新增使用真实实例运行时的卡片呈现测试，检查可发现的折叠标题、展开不改变播放状态、初始平抛结果及速度/高度/重力编辑后的代入与结果。新增斜抛、非零地面高度与零重力推导测试；在服务器候选 Docker 运行，确认因缺失功能失败。
2. 在 `CanvasInstanceViews.tsx` 复用 `DataPanelBody(tab="derivation")` 增加折叠区，添加中英标题与小型局部样式。修正 `mechanics-view-builders.ts` 平抛/斜抛推导分支，保持其他模型原样。
3. 在同一服务器 Docker 运行新测试、现有机械运行时和 Canvas 实例呈现测试，执行该 UI 包 TypeScript 检查与 diff 空白检查。记录证据、文件清单与限制，交由主任务整合到同一候选发布；本子任务不提交、推送或切换生产。

## 审查重点

- 当前参数变化后不能保留旧示例数据。
- 斜抛不能使用仅适用于平抛的下落时间公式。
- 非零地面高度须使用距地面的相对高度。
- 零重力不能展示除零或虚构落地结果。
- 展开公式不能创建另一个实验或改变运行时状态。
