## 审查与选择

并行检查前端加载/实验帧、后端存储/API、反向代理及发布配置。已启用的 gzip、HTTP/2、公开实验内容不可变缓存保持现状。前轮已发布的场景帧缓存、同步并发限制、轮询串行化等不重复实施。选择以下已测量路径：

1. 班级完成看板：每名学生、每个作业扫描全部提交，改为请求内一次聚合。500 学生 × 500 作业的固定夹具测量 5 次取中位数；回归覆盖缺交、待审、接受、退回、已退班历史记录及权限。
2. 题库组卷：每个候选题多次扫描使用历史，改为本次规划专用索引。固定题库/历史记录测量；保持相同排名、示例、回退、学校隔离及新写入可见性。
3. 复合场动画：运行时持有的不可变仿真每帧重新提取轨迹和区域，改为运行时私有预处理投影。120 帧固定参数测量；参数改变必须重建，外部可变输入仍实时计算，不裁剪轨迹或改变物理数据。
4. 页面启动：候选首页三次冷启动为 6.1–6.4 秒，插件预加载解码约 11.58 MB；账号设置模块约 5.28 MB，其中八张上游引导 PNG 约占 5.07 MB。检查不展示的引导资源如何脱离预加载路径，保留账号设置功能，用相同浏览器冷启动与实际传输字节复核。

## 验证与发布顺序

- 先在旧源码运行新增正确性/工作量回归，记录预期失败与原始基准，再实施优化。
- 在同一容器、同一数据集复测；测试以数据访问次数约束复杂度，不以机器耗时设脆弱阈值。耗时只作对照报告。
- 运行受影响宿主及 UI 回归、严格类型检查、lint，独立审查修改。
- 从当前生产镜像构建不可变候选，冻结 Git 源码和完整运行文件清单；显式覆盖 class-host、paper-host、ui-physicsos 和 web 构建输出，拒绝未处理的运行目录。
