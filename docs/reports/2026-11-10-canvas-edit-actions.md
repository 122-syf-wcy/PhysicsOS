# 器材自由搭配与快捷编辑上线

用户授权自主改善自由器材画布并直接部署。最终代码 3e8c5e427e36ff524daa3cbcf09c997f6a40c35e，正式入口 https://physics.dongsiwei.com。

## 行为

- 非电源器材可复制规格、参数与朝向，生成独立 ID 和未接线端子，自动进入空位。复制成功后选中新器材，失败或较晚确认不覆盖新的选择。每台保留一个电源，通过电源选型更换规格。
- 直接获得焦点的器材本体支持方向键微调（0.5，Shift 为 2）、R 旋转、Delete / Backspace 删除、Ctrl / Command + D 复制。输入框、接线柱与滑动变阻器保留原有按键。
- 位置移动在串行操作队列中解析相对位移，保持实验时间。复制、旋转、删除和选择同一次所有者操作完成；撤销排在该队列，另一显示位置不能抢占预览。
- 重载时先通过账号、资源策略与远端列表检查，再恢复已验证的本地画布、器材与历史，保留上传在后台继续。首次对象读入与确认相撞时保留不可变对象，并重新校验最新工作图后才标为加载完成。
