# 器材复制与键盘编辑

用户要求继续改善自由器材画布，并授权自主决策和直接部署。

## 改动

- 非电源器材可复制同规格，保留参数和朝向；每份器材有独立 ID 和未接线端子，自动放入空位。复制后选中新器材，失败或卸载后不更新选择。
- 仅直接获得焦点的器材本体响应快捷键：方向键移动 0.5，Shift 移动 2；R 旋转，Delete / Backspace 删除，Ctrl / Command + D 复制。电源保持每台一个。
- 移动使用既有位置提交，保留实验播放时间；输入框、接线柱和滑动变阻器仍使用自己的按键。结构编辑经画布原生队列与当前搭建模式检查，不能抢占另一显示位置的预览，拒绝修改不触发成功选择。
- 所有动作沿用现有实验历史与保存流程，操作提示和复制按钮覆盖中英文。
