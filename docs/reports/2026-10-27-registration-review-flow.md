# 注册审核流程与邮件通知（2026-10-27）

## 1. 问题

注册时学校是自由文本框，服务端只匹配贵州花名册，未命中直接报「未找到该学校」。
学生看不到名录、没有申请入口、也不知道为什么失败。

## 2. 现在的流程

```
输入校名 ──> GET /physicsos/auth/schools?q=  ──> 快速选项（精确 > 前缀 > 子串）
   │
   ├─ 选中 ──> 带上 schoolId 注册 ──> 201 直接登录
   │
   └─ 无匹配 ──> 仍可提交 ──> 202 挂起
                    │
                    ├ 建占位租户（status=disabled, reviewState=pending）
                    ├ 建学校申请（同校申请人共用一个申请）
                    └ 凭据入库（密码已 argon2 哈希）
                              │
              管理员点「审批通过」（一键，无需填表）
                              │
                    ├ 占位租户转为 active，学校进入花名册
                    ├ 所有挂起注册转为真实账号
                    └ 逐个发 HTML 邮件通知
```

关键设计：

- **占位租户用 `reviewState` 而非新增 status 值**。`resolveSchoolByName` 只匹配
  active 行，所有会话/凭据校验也只认 active 租户，所以待审核学校对登录路径天然
  不可见——不需要在每处判断里加分支。
- **挂起注册不写 `users`**。学校可能永远不被批准，不能留下半真实账号；管理员
  在名录里看到的永远是「批准过的」。密码在挂起时就哈希，审批只是物化那一行。
- **待审核不是静默黑洞**。用正确密码登录会返回 `ACCOUNT_PENDING` 并指出学校名；
  验证在披露之前完成，所以不能被用来枚举待审核用户名。
- **驳回会清理占位租户**（仅当它仍是未被使用的占位），否则该校名会永久无法再申请。

## 3. 邮件

QQ 邮箱，465 端口隐式 TLS + `AUTH LOGIN`。凭据走 Compose secret
（`.env.smtp_user` / `.env.smtp_password`），不进 environment 明文、不进日志。

正文是 `multipart/alternative`：
- HTML 主件用表格布局 + 全内联样式（Outlook 没有 flex/grid，Gmail 会剥 `<style>`），
  600px 卡片在手机上自动收缩，中日韩字体栈两端都覆盖；
- 纯文本副件保留，供纯文本客户端与反垃圾评分使用；
- 标题用 RFC 2047 编码字传中文，不直接塞 UTF-8 字节。

发信器是 `node:tls` 上手写的约 150 行客户端，不引依赖——这台主机上行约
1.2MB/s，每加一个包都是一次可能失败的镜像构建。发信是尽力而为：账号已经开通，
邮箱故障只记在待审核行上，不回滚审批。

## 4. 部署要点

- `.env`：`PHYSICSOS_ADMIN_USERNAME=PhysicsOS`、`PHYSICSOS_PUBLIC_URL=…`
- `.env.admin_password`：新引导管理员密码
- 新增两个 secret：`.env.smtp_user`（QQ 邮箱地址）、`.env.smtp_password`（授权码）

**换管理员账号有一个坑**：auth 域的存储是进程内快照 + 定期/停机写回。直接在数据库
删掉一行，运行中的进程会在下次写回时把它恢复（实测重启后旧账号仍可登录）。正确
顺序是 **先 `docker compose stop app`，再删行，最后 start**。同时把
`PHYSICSOS_ADMIN_USERNAME` 改成新名字，旧名才不会在下次启动时被重新种回来。

## 5. 验收（2026-10-27 实测）

| 项 | 结果 |
| --- | --- |
| 首页 / `/readyz` | 200 / 200 |
| 校名关键字搜索 | 200，返回带地区标签的候选项 |
| 未开通学校注册 | 202，返回待审核回执 |
| 待审核账号登录 | 403 `ACCOUNT_PENDING`，提示学校名 |
| 一键审批 | 200，`activated[].emailSent: true`，耗时 ~1.1s |
| 审批后账号登录 | 200 |
| 审批后校名进入花名册 | 搜索可命中 |
| 缺少邮箱注册 | 400 |
| 跨站 Origin | 403（安全未放宽） |
| 旧管理员 `admin` 登录 | 401（已删除） |
| 新管理员 `PhysicsOS` 登录 | 200 |
