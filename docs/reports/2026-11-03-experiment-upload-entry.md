# 实验上传入口与液态玻璃控件

## 问题与方向

用户在正式站点找不到实验上传，随后要求把截图中的原生英文文件按钮改成液态玻璃风格。核对发现：正式服务仍是 `33023a2`，上传 API 返回404；完整上传宿主和审核闭环已在开发分支，原工作区的贡献页则仍是“待接入”的介绍页。

独立文件包、平台物理引擎、隔离三维预览、管理员审核后自动展示的方向保留。本轮接通产品入口并优化控件，没有另建后端，也没有改变原有权限、ZIP限制或版本发布规则。

## 已实现

- 侧栏“实验上传”、实验中心入口与 `/#/contribute` 统一打开真实表单。明确当前支持凸透镜；模板、文档、投稿记录和打开实验均有入口。
- 原凸透镜页“贡献实验”弹窗保留，与新页面使用同一个上传/预览/审核组件。页面模式没有模态遮罩、焦点陷阱或 Escape 关闭行为。
- ZIP与头像保留系统文件选择器，前台改为中文玻璃按钮，显示文件名和大小，可更换、移除；移除后焦点回到选择按钮。原生英文控件不再直接展示。
- 按钮、输入框、文件卡片复用平台 `--physics-glass-*` 材质，使用半透明填充、高光边缘、背景模糊、轻阴影和按压反馈；主要提交按钮使用浅绿玻璃渐变。响应式文件操作会换行，减少动态效果时不移动按钮。
- 401及非JSON404显示清楚的登录/服务错误，允许刷新重试；首次目录加载失败时不能提交假成功。
- 修正实验加载期间和账户同步期间的导航竞态，保留用户新选择及正在进行的实验。`index.ts` 在账户同步前捕获页面状态；桥接启动时仅在状态未改变的情况下应用旧地址。
