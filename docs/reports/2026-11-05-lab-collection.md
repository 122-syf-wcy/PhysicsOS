# 76 个独立三维实验包

## 范围

本次为现有目录的全部 76 个实验、12 个物理领域制作独立 V3 上传包。每包包含实际源码、构建入口、标准元数据、平台默认快照、Three.js 0.180.0、材质与许可证。正式发布记录和最终验收摘要在切换完成后补充；本段不表示已经上线。

三维器材包括精加工光具座、厚透镜与环形镜架、蜡烛、光屏、夹具、滚花旋钮、轨道与小车、橡胶轮胎和金属轮毂、电表、电阻绕组、接线柱、磁场线圈、液体容器与温度计等。统一采用物理材质、工作室反射、柔和阴影、完整标注、装置近景/全程/正视取景以及手机布局。

生成的台面纹理仅承担装饰，采用用户指定的 gpt-image-2.5-sunburst，经 imagegen CLI 生成。源提示词见 `experiment-packages/lab-collection/SURFACE-PROMPT.txt`，原图留在任务 `output/imagegen/lab-premium/`。实际物理量、装置位置、光线、波形与轨迹全部由平台引擎提供，渲染包不包含第二套求解器。密钥沿用服务器已有私密文件，未写入源码或报告。

领域数量：力学 24、光学 6、声学 2、波动 7、流体 4、热学 4、电场 4、磁场 5、电路 8、复合场 6、电磁感应 5、近代物理 1。

## 物理与交互修正

- 圆周运动的瞬时加速度/合力派生量使用真实轨道状态，重力观察向量改为径向吸引，并读取当前帧合力。
- 斜面旋转方向与下滑方向一致，支撑面按质心与可视物体尺寸映射；摩擦面不再穿过物体质心。
- 弹簧原长参考与实时线圈端点使用相同的物体连接面偏移，保留真实约束原长和质心。
- 波的折射传播方向保留切向方向并穿过界面；零磁场区域不再显示非零磁场标记。
- 感应导轨和闭合电阻固定于实验室坐标，导杆相对回路真实移动；相机取景与世界坐标分开。
- 数值控件按平台有限值和上下限校验，避免浏览器步长格点误拒合法参数。
- 显示开关涵盖浮力排开体积标注、温标刻度、比较磁场与变压器匝数；声源固定、绳波驱动连杆跟随真实端点。
- 所有视角使用同一坐标比例，按相机实际投影的八个边界角点取景；零尺寸或 WebGL 丢失不发送虚假的绘制成功回执。
- 替换画面后再释放上一帧材质，避免每帧重新编译 GPU 程序。相同快照的程序创建计数由 `13,20,27,34` 改为 `13,13,13,13`。

本轮另外尝试了根目录 `pnpm test`。构建容器默认 pnpm 依赖自检会尝试重装，设置 `pnpm_config_verify_deps_before_run=false` 后沿用已有依赖运行。补齐 Git 和可用源码路径索引后，整库测试仍在 image-generation 的三项源码扫描测试停止：

- `secret hygiene > no tracked file contains credential material`：构建容器保留的模型池旧测试中三处假凭据字面量触发扫描（`proxy.spec.ts:198/225/246`）；这些测试不属于本次改动，且构建容器旧测试文件摘要与生产源码基线不同。

这次未削弱扫描规则或将整库测试报告为通过。上述专项物理、模板、渲染与全部实验浏览器验收独立通过。真实页面测试还修正了测试工具设置：Playwright 的 `serviceWorkers: block` 注入脚本会在缺少 allow-same-origin 的沙箱 iframe 读取 navigator.serviceWorker 而抛错；使用没有已安装 worker 的新浏览器上下文后，该错误消失，沙箱权限保持原配置。
