## 功能

SUPER_ADMIN 后台增加「对话审核」，显示可信服务器归属的用户文本、AI 风险建议及人工处理记录，支持分页筛选、证据查看、误报驳回、重试、自动审查开关和每次最多 20 条的历史补扫。人工封禁必须填写理由并确认目标；AI 只提供建议，不选择账号或执行封禁。

审核采用固定部署模型、固定政策和无工具接口，用户对话作为不可信 JSON 数据。输出枚举、长度、完成状态和证据原文严格校验；失败、截断和低置信度进入人工复核。人工决定使用版本控制，迟到的模型结果不能覆盖人工处理。记录、游标、决定及恢复边界持久化。

账号停用撤销登录和个人 API token，取消实际归属的根 Agent 与可信子 Agent，并在 Connection → Peer → Gateway 链路拒绝旧连接的输入、开流和排队输出。保留学校合并与启动恢复机制。

左侧导航与历史列表现在有明确的可滚动区域，账户和设置保持可见。实验生成区提供「检查并恢复生成」；后台保留真实运行任务，恢复没有实际进程任务的卡住状态，失败清理只更新仍由本任务持有的场景。真实素材超时、HTTP 429 或 5xx 可以在严格身份绑定后使用原生 Canvas/SVG；永久错误、取消、伪造提示及跨绑定不授予降级权限。

两份学生预设调整为更自然的讲解：打招呼简短友好，概念先讲生活直觉和必要公式，计算题保留规范步骤。预设要求学生回答不展示引擎、工具、校验计数或后台日志；数值仍由物理工具核对，结构化协议与代码验证保持原规则。
