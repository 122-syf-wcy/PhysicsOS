# 官网与后台管理发布记录

## 范围与基线

用户先确认液态玻璃官网设计、动效和现有管理员后台中的官网管理页，随后明确要求「部署上线」。原桌面工作区的其他未提交修改未纳入本次发布；在隔离分支从远端 `main` 构建。

开始核对时：远端 `1efe1ff`，生产源码 `63b17e1`，运行镜像 `49e1960a`。发布过程中远端新增性能优化 `3d92edc`，随后生产切换至 `75036307a61ac7842a59d1451ae803c7be89b37aa91b958dc6a25eab3c7662b1`。本分支已合并该提交，最终官网镜像以这份实际生产镜像为基础，保留已上线性能优化及实验功能。

官网运行源码包含合并提交 `109cf516e1795736b764ec8acfa4869011bda2f4`；镜像中保存 `website-source-manifest.json`，核对 41 个变更源文件的 SHA256。打包只覆盖验证过的官网、管理员界面及相关宿主产物，基础镜像中的其他功能和运行配置保留。

## 实现

- `/` 为公开官网，`/app` 和 `/app/` 为原产品入口。原 API、资源和 WebSocket 路径保留。
- 旧实验/投稿 hash 和密码重置链接兼容；PWA 以 `id: /` 保持历史身份，启动地址为 `/app`。
- SUPER_ADMIN 的「管理后台 → 内容与通知 → 官网管理」支持展示反馈、贡献者头像/项目、排序、上下架、发布预览和版本冲突提示。
- 独立官网反馈收件箱支持匿名截图提交、筛选分页、管理员查看截图、回复/关闭和转为未发布展示草稿。
- 公共 DTO 排除原始截图、联系方式和来源反馈 ID。管理写入限定 Cookie 登录会话，拒绝 Authorization 头，避免只读个人令牌越权。
- 图片通过既有附件系统校验、规范化和持久化；反馈独立存入 `physicsos_notice.website_feedback`，官网配置存入 `website_content`，域版本保持 0。
- 官网没有示例数据播种；默认展示内容为空，候选验收数据只存在于隔离数据库。动效偏好可保留在浏览器，内容和反馈使用真实服务端接口。
