## 修复

1. **教学画板草稿恢复。** 关闭前尚未自动保存的草稿，重开并校验服务器版本后会重新安排自动保存；版本冲突和远端读取失败继续保留草稿，不绕过冲突保护。
2. **学习记录分页。** 排序与游标过滤统一使用不依赖语言区域的比较。同一时间的大小写、数字及连字符 ID 不再漏项，原游标格式保持兼容。
3. **作业时间。** 迟交及排序比较真实时间戳，支持 `+08:00`、`-08:00` 与 `Z` 混用，也修正已经存储的偏移格式，无需重写历史记录。该保留模块在当前产品中已下架，本轮未重新启用；验证为源码与服务回归，不宣称主站开放作业入口。
4. **多普勒模型适用域。** 远离观察者达到或超过波速时返回不支持的模型，不输出带验证成功标记的非正频率；保留临界以下精度以及迎向来波的合法高速情形。
5. **实验参数回读验收。** 单位转换后的回读采用 `8 × Number.EPSILON` 相对容差，同时拒绝缺失、非数值和无穷值。不修改物理数值，不使用固定绝对容差，发送的参数仍严格比较。
6. **波动演示时间。** 切换衍射图层不再将后段时刻从 4 秒截回 1 秒。先取得新模型的实际演示窗口再截断时间和保存帧，保持物理时刻与帧一致。
7. **运维工具的 Docker 配置。** 为只读工具容器设置独立可写的 Docker 配置目录，修复镜像构建向 `/root/.docker` 写入失败，同时继续隔离宿主和镜像的凭据配置。
8. **发布依赖解析。** 使用已有 TypeScript 语法树提取真实 import/export/require，修复将正则或字符串片段误识别成依赖、导致镜像生成失败的问题；保留子路径检查和语法错误拒绝。
9. **客户端 UUID 兼容性。** 候选浏览器复现新建画板时 `crypto.randomUUID` 不可用；统一使用项目已有的安全 UUID 工具，其底层为 `getRandomValues`，并覆盖画布、学习记录和官网后台的同类调用，保留标识格式与安全随机性。

另外恢复了一批失效的回归夹具：登录状态使用完整学生身份；用量事件与统计窗口共用测试时钟；对当前入口、场景防御复制、恢复后的分支身份、结构错误提示和异步保存完成条件做精确断言。没有修改产品来迁就旧 mock，也没有删除原有业务检查。
