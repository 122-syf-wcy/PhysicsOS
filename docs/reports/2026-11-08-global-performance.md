# 全局性能优化

## 基线和发布范围

正式入口为 `https://physics.dongsiwei.com`。开始时远端 main 和服务器 `/opt/physicsos` 均为 `1efe1ff`；运行镜像为 `49e1960a9b7d`，源码标记 `63b17e1`，其后的提交仅为文档。所有构建、测试和基准在 `107.151.246.59` 的 Docker 中执行。

审查覆盖网页加载、实验动画、服务端统计、题库规划、存储访问和代理配置。gzip、HTTP/2、公开实验不可变缓存及上一轮帧缓存/并发限制已经存在。本次处理四个有测量依据的热点，未改变数据库结构、权限或模型通道。

## 已实现的优化与测量

| 路径 | 同一数据集/方法 | 优化前 | 优化后 |
| --- | --- | ---: | ---: |
| 班级完成看板 | 500 学生、500 作业、187,500 份提交，5 次测量中位数 | 22,010.7 ms | 67.7 ms |
| 题库规划 | 300 题、5,000 条使用及试卷记录、16 个出题位置，3 次中位数 | 9,078.6 ms | 10.9 ms |
| 复合场动画 | 三类实验分别推进 120 帧，读取已有采样对象次数 | 28,920–30,000 | 0 |
| 网页账号入口 | 当前生产包与新构建包实际 JavaScript 字节数 | 5,276,730 | 1,576 |

前两项测量使用内存数据夹具执行真实服务函数，只衡量计算，不包含数据库或上游模型网络等待。测试以工作量预算约束复杂度，不设置机器耗时阈值。

同一候选入口、各三个新浏览器上下文的对照中，页面资源解码量从 16,178,662 降至 10,902,110 字节；最长主线程任务中位数从 922 降至 647 ms，界面就绪中位数从 6,399 降至 5,899 ms。网络传输量仍约 3.74 MB。这是小样本服务器浏览器测量，不能外推为所有设备的加载时间。

- 看板将按学生、按作业反复过滤提交改成请求内一次聚合，保留批改状态、排序、历史退班提交及原有比例规则。
- 组卷对本次已限定学校范围的近期使用记录建立索引，保留选题排名、排重、示例题和下一次请求读取新数据的行为。
- 复合场运行时按场景修订缓存复制后的轨迹、区域和静态边界。参数变更会重建，当前粒子仍逐帧参与取景；完整采样和时间轴保留。直接调用的外部可变输入仍重新计算。
- 账号入口在普通网页中不加载桌面实现及八张引导图片。桌面实现逐字保留，按需加载独立工厂；处理加载失败及等待期间卸载。入口保留所有本地桌面源码、资源和配置的内容指纹，保证后续桌面更新同时更新缓存版本。
