# 器材画布状态一致性改进

用户再次要求继续，保留自主选择与直接上线授权。

## 修改

- 无效数值被拒绝后恢复最新已提交值，并在器材属性附近显示反馈；有效修正清除本地提示。
- 异步提交失败或较早成功的确认不能覆盖新输入；真实外部更新、撤销和空值回退仍同步已提交值。
- 撤销/重做前筛选仍存在的器材，先更新内部选择再创建显示帧；撤销新增器材清除已移除的选择。
- 有效无变化编辑清除先前输入拒绝诊断，保持物理修订不变。
- 退出搭建时清除已捕获的本地接线手势；搭建之外不接受延迟的开始/完成连线。
