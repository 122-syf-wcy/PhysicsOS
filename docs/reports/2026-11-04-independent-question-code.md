## 最终行为

- 引擎校验解题成功后，主对话调用受限代码子代理，生成自己的 Canvas 2D 或原生 SVG 画面；不提供旧渲染器实现，禁止模块导入和旧绘图调用。物体位置、轨迹、时间、参数与量测来自现有引擎快照。
- 新私有实验使用独立视口与冻结的基础字体样式，再加载作者的原始 CSS。标题、布局、材质、标注和画面由生成代码交付；原始四个源码字符串可以查看，封闭资源、哈希和账号归属继续校验。
- 聊天与私有实验室使用宽画面、玻璃控件和源码入口。条件编辑、播放、步进、时间拖动与恢复原题使用同一运行时。手机布局将源码、再生成与播放控件分行。
- 历史旧代码版本显示手动升级入口，读取历史不会自动生成。每轮同场景版本只保留一个任务，成功结果不会被主代理后续调用覆盖；最多一次代码校验修复，共享 300 秒期限。
- 主对话的模型、高推理配置与原预算保持。子代理仅可调用 `structured_output`，预算不超过 8192 且尊重更低父预算；使用模型公布的最低推理档。现有模型路由的两字段兼容迁移保留独立备份和回滚。
- 社区上传、审核、实验默认版本及已发布提示词流程继续独立运行。
