# PhysicsOS 全局修复验收记录

日期：2026-10-08。基线：`14157e1`。修复分支：`codex/global-reliability`。

本轮针对全局审阅中复现的问题以及“测试 key 成功但聊天失败”的后续反馈实施修复。改动保存在独立工作区；没有修改生产服务、生产数据或真实模型密钥。

## 交付

1. **数据写入与账号操作**：题库、模板和批注创建采用按存储域串行的新增检查，拒绝覆盖已有学校或平台记录。邀请码与密码重置的消费、失败补偿和管理员禁用/撤销按同一队列处理，保留正确存储键及原状态。
2. **物理结果**：统一绝对时刻与区间累计量语义，修复非零起点下的力学/碰撞结果；观察层共同拒绝失败或 revision 不匹配的模拟。补充独立力学校验、Agent 缓存版本及淘汰规则，并让各引擎的实际事件限制在请求区间内。
3. **共享能力**：新增 `packages/physics-runtime`，题目与 Agent 共享引擎、请求和验证分派；现代物理光电效应可通过 Agent 入口使用。公共契约覆盖范围、采样、版本和事件边界。
4. **实验状态和学习**：离散编辑回写最新场景，保存题目来源和自由搭建模式；切换、继续、刷新及远端恢复保留版本。同步队列在执行时读取最新记录，防止旧快照覆盖或删除项复活；学习记录采用待同步队列和联网重试，推荐会识别近期掌握恢复。
5. **前端性能与交互**：动态电场/电路按 revision 缓存完整模拟，力学静态面板数据不再逐帧重建。实验工作区、后台和 PDF 成为独立工厂文件，宿主支持受限文件名的按需加载。统一模态焦点及背景快捷键规则。
6. **服务可靠性**：PostgreSQL 持有独立会话级写入租约，启动失败释放租约，第二个写入者被拒绝，租约丢失停止进程。就绪检查实际验证 PostgreSQL/Redis 协议与认证。部署等待健康状态，使用容器内 Node 进行就绪确认。
7. **备份和桌面**：新增完整加密备份、校验清单、可选异地复制与限定新项目的隔离恢复；定时全备份预检宿主 Node，保留策略只处理明确命名的旧归档。桌面启动有可见状态、诊断、超时、进程清理和重试，真实桥接测试不再隐藏启动失败或跳过缺失构建。
8. **工程门禁**：依赖检查拒绝跨工作区链接及 React 多实例；测试服务不再复用个人配置或密钥。CI 增加上游接口、数据库、Agent 与浏览器验收，发布镜像绑定已验证的提交。overlay 支持全量一致性检查、受控删除、暂存补丁捕获，排除 TypeScript 生成伴生文件。

## key 测试误报的原因与修复

原探测请求使用 `stream: false`、`max_tokens: 1`，收到 HTTP 200 后取消读取响应正文，立即显示“连通正常”。因此错误 HTML、错误 JSON 或仅非流式可用的网关都可能通过，实际流式聊天却在缺少 `finish_reason` 时失败。

现在探测使用通道配置的首个模型、`stream: true`，消费并验证完整 SSE。健康状态只在完整响应验证后更新；不完整响应不会清空连续失败计数。代理只转发已完整校验的 SSE 帧，截断尾部不会污染独立错误事件；客户端取消和请求参数错误不会误伤 key 健康状态。已经发出的响应不再触发付费重放。

截图中的 Base URL 是纯域名，原代码会拼接 `/chat/completions`。现在纯域名统一默认 `/v1`，已有 `/v1` 和显式自定义路径保持不变。此为 OpenAI 兼容约定；未对截图中的真实网关发起请求，不据此断言其实际响应内容。探测只证明基础流式响应，工具调用和其他思考配置仍应分别验收。

## 运行边界

- 本轮未上线，未使用用户真实 key 验证第三方网关，未触及生产数据或轮换密钥。
- 当前仍为单写入者架构；租约阻止误扩容，不等于已经实现多副本业务缓存一致性。
- 跨记录补偿覆盖进程内并发与观察到的写入失败；没有宣称进程崩溃期间的跨表 ACID 事务。
- 当前环境没有可用 Docker daemon，完整容器恢复、异地副本及生产 RPO/RTO 仍需按 `docs/restore-drill.md` 实测。定时全备份需要配置独立保存的加密 key 文件，代码提交不会自动改变生产定时任务。
- 原生 Rust、启动页与本地桥接已验证；签名、公证及安装发行不在本轮交付内。
