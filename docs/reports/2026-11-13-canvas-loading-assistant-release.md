## 本轮修出的真实缺陷

1. **出厂插件清单过期**：改动 `learning-host/src/index.ts` 后未重签，`export` 阶段直接失败。已按私钥重签，之后每次改该文件都需重签。
2. **推理通道吃掉全部预算**：模型在 `max_tokens: 8000` 下把整个预算用于 reasoning，`finish=length`、无工具调用，任务稳定失败。改为显式下发最轻可用档位，并把预算下限提到 4000。
3. **提案 schema 过大**：7.5 KB 的 `anyOf` 联合让模型长推理。改为约 2 KB 的紧凑字段表 + 一句必填字段说明，权威校验仍由 `parseCanvasAnnotations` 负责。
4. **`rgba()` 颜色被拒**：模型会输出 `rgba(0,0,0,0)`，旧校验器只认 hex/颜色名，导致合法提案被判「未通过安全检查」。已接受 `rgb()/rgba()`，仍拒绝 `url()`、`var()` 等可执行写法。
5. **诊断信息被抹平**：模型失败码被统一压成 `MODEL_FAILED`，且发布脚本 `catch {}` 丢弃原始异常，排查时看不到原因。现在失败码写服务端日志，发布前检失败会透出原因。
