# 实验自由画布：使用与维护

实验自由画布把独立实验、结果证据、比较和笔记保存在同一工作台中。工作台的位置、分组与视口属于展示布局；卡片之间的排列和关系不会建立物理耦合。

本文跟随本次候选源码说明已接通的接口和使用路径，不表示最终全栈验收已通过或候选已切换到生产。正式入口是 `https://physics.dongsiwei.com`；发布状态应以服务器发布记录和验收证据为准。

## 进入和管理工作台

- 侧栏的“实验自由画布”打开工作台目录；首页提供打开画布、新建工作台的入口。
- 单实验室、实验中心、最近实验与对话实验卡的“加入画布”打开工作台选择器。可以加入已有工作台，也可以新建后加入；加入的是独立实验副本，保留来源和原题条件。
- 工作台目录支持名称搜索，按更新时间、创建时间或名称排序，以及新建、重命名、复制、导入、导出、删除和查看已删除工作台后的恢复。
- `#/canvases` 打开目录，`#/canvases/<编码后的工作台ID>` 打开指定工作台。无效地址不制造替代文档；账号权限、删除状态和读取错误由实际数据与接口决定。

复制整个工作台会生成新的工作台、实验实例和当前场景身份。导入 `.physicsos-canvas.json` 也会校验完整对象引用并生成独立身份；不会把导入文件中的账号或服务器验证声明当作授权。

## 独立实验和专注编辑

“添加实验”使用现有实验中心的可运行模板与真实场景。自由电路搭建保留器材、参数、端子连接和草稿；尚未形成可解电路仍可保存，保存成功与物理校验通过是两个状态。

每张实验卡独立拥有场景、时钟、参数编辑、运行状态、读数和编辑历史。可以把同一模板加入多次，分别修改条件和运行。卡片上的播放、倍率、时间游标、参数编辑和“记录结果”作用于该实例；静态实验直接显示静态结果，不伪造播放时间轴。

卡片的“专注编辑”打开完整编辑器。它与卡片读写同一个实例，包含器材或场景树、参数和读数、校验、时间轴、数据、图表、推导、事件、指南和报告。关闭专注视图后，实例条件和画布位置保留。“在独立实验室副本中打开”创建新的实验室副本，原画布实例继续独立存在。

退出专注视图或器材失去指针捕获时，该显示视图正在进行的未提交预览会取消，恢复已提交条件。另一显示视图正在操作的预览仍由其自身拥有，关闭未参与操作的视图不会替它提交或取消。

实验的首次事实编辑保留原题并建立当前编辑分支。“恢复原题”把原题事实物化为当前实例的新修订；不会把当前场景版本倒退到旧版本。复制实验或由快照复现实验也不会修改来源实例。

## 画布布局和笔记

拖动卡片标题可以移动卡片，选中未锁定卡片后可调整大小。画布支持框选、多选、分组与解组、折叠分组、对齐和分布、层级调整、锁定、复制粘贴、搜索定位、适合内容、小地图与平移缩放。锁定保护布局，实验内部操作仍由实例自身控制。

卡片菜单“复制卡片”立即创建独立副本。工具栏“复制所选内容”把选择放入工作台剪贴板，随后使用“粘贴”加入副本。

布局撤销与实验编辑撤销分开：工具栏撤销恢复节点、位置、笔记或比较等工作台编辑；专注编辑中的“撤销实验编辑”恢复该实例的参数、器材、接线等物理编辑。移动卡片的撤销不会顺带回滚另一个实验的参数。一次完成的拖动是一个布局操作。

添加笔记后可以编辑纯文本或安全 Markdown、预览、复制和删除。停笔后正文和格式自动保存到工作台，编辑器保持打开；自动保存期间继续输入的内容会在下一次停笔后续存。也可以点击“保存”或按 `Ctrl/⌘ Enter` 立即保存并结束编辑。保存错误保留草稿并停止自动重试，修复存储问题后可手工“保存”重试。另一处编辑同时改变正文时，当前输入不会被替换，界面会提示冲突并停止自动覆盖。

切换到其他工作台不会丢弃尚未到停笔期限或保存期间输入的最新笔记；返回后继续查看与保存。工作台保存、导出和复制会包含当前笔记草稿的保存过程。尚未完成本地持久化事务的内容仍属于待保存状态，不能把浏览器骤停前的未完成输入当作已形成恢复点。

画布获得焦点时的主要快捷键如下。输入框、菜单、弹窗和实验内部控件保留各自的键盘行为。

| 操作 | 快捷键 |
| --- | --- |
| 临时平移 | 按住空格并拖动 |
| 选择可见节点 | `Ctrl/⌘ A` |
| 复制、粘贴所选节点 | `Ctrl/⌘ C`、`Ctrl/⌘ V` |
| 分组、解组 | `Ctrl/⌘ G`、`Ctrl/⌘ Shift G` |
| 撤销、重做工作台编辑 | `Ctrl/⌘ Z`、`Ctrl/⌘ Shift Z` 或 `Ctrl/⌘ Y` |
| 移动所选布局 | 方向键；按住 `Shift` 使用较大步长 |
| 删除所选未锁定节点 | `Delete` 或 `Backspace` |
| 适合全部、适合所选 | `F`、`Shift F` |
| 搜索定位 | `Ctrl/⌘ F` |
| 添加笔记、切换选择与手形工具 | `N`、`H` |
| 清除画布选择和布局预览 | `Escape` |
| 立即保存笔记 | 笔记输入框内 `Ctrl/⌘ Enter` |

实验内容区域的滚动、输入、滑杆、器材拖动和接线与外层布局操作分开。实验区域获得焦点时，空格控制该实例播放，左右方向键改变游标，`Home` 回到起点，`Ctrl/⌘ Z` 使用该实例的编辑历史。

自由电路端子支持点按、触屏或笔拖动，以及聚焦端子后的 `Enter`/空格接线。待接线时先按 `Escape` 取消当前端子，不产生物理编辑；之后的 `Escape` 再由弹窗或画布处理。器材手势先通过实际 SVG 屏幕变换换算为场景坐标，外层工作台缩放和 SVG 留白不会被当作物理位移；不可逆或未测量的坐标不会提交器材编辑。

## 记录结果、比较和导出

“记录结果”读取该实例真正持有的已提交场景、请求、引擎输出、当前时刻与完整已计算数据。尚未完成的参数或器材预览需要先完成或取消，再记录。快照固定记录时的条件、修订、真实数值、读数、原始采样、推导、事件和校验信息；之后修改或删除来源实验不会改变快照。

结果节点支持查看条件、数值与分析数据，修改显示名、导出、删除，以及“从快照复现实验”。复现会建立新的独立实验，保留捕获条件和来源信息，不把历史结果变成正在更新的实时读数。

结果卡菜单“隐藏结果卡片”移除当前展示卡片。结果工具栏“删除快照”经确认后移除该快照、它的全部结果卡和比较引用，来源实验继续独立保留；历史保留和对象回收仍遵循工作台的数据保留规则。

在线复验由服务器读取授权的不可变场景和捕获请求，调用注册的物理引擎。复验产生独立记录和证据，原始快照保持不变。`rejected`、`unsupported`、`error` 都不是验证通过；离线客户端捕获和导入的验证声明不会自动取得服务器验证身份。结果页面保留历次复验记录及其明确的验证范围。

选择至少两份结果，使用工具栏“比较”创建比较节点。比较节点可添加、删除、选择物理量和横轴，以及使用条件并列、兼容曲线叠加或两份数据的差值。兼容判断同时考虑物理量含义、目标和分量、单位、坐标基准、尺度与参考、横轴含义；不兼容时保留原数据并说明原因。差值只使用真实匹配的采样坐标，不引入未验证的插值或归一化。

CSV 来自已保存的完整原始数据，而不是界面的分页、显示精度或曲线降采样。导出保留条件、描述、原始双精度数值、缺测原因和行证据，并处理 CSV 转义及电子表格公式注入。完整工作台 JSON 导出适合作为个人数据备份；CSV 适合作为外部分析的原始数据。

## 保存、断网和账号切换

工作台同时有浏览器 IndexedDB 草稿和账号同步状态。编辑先经过本地事务，只有事务完成才显示本地已保存；上传对象后，服务器持久提交 head 才算保存到账号。

| 界面状态 | 含义和操作 |
| --- | --- |
| 正在载入、尚未保存 | 不表示已经形成可恢复保存点 |
| 正在保存到本机 | 浏览器持久化事务尚未完成 |
| 已保存到本机，等待同步 | 当前浏览器有草稿；仍需联网与账号同步 |
| 正在同步到账号 | 正在上传对象或提交工作台版本 |
| 已保存到账号 | 该版本已获服务器持久提交确认 |
| 保存失败，内容已保留 | 查看具体错误，可重试或导出保留内容 |
| 有版本冲突 | 本地和远端内容均保留，按冲突处理入口选择 |
| 登录后继续同步 | 认证作用域暂停写入，重新认证后显式重试 |
| 已删除 | 文档有删除标记，恢复需使用明确恢复操作 |

断网时已保存的浏览器草稿、不可变对象和待同步操作保留在原作用域。网络恢复、重新聚焦或手工重试会继续可重试的同步；重试沿用已发送操作的身份，避免重复创建文档或快照。`401/403` 停止旧认证作用域写入，版本冲突保留双方，超出配额或格式错误停止并提示，不会把失败显示成成功，也不会截断数据。

不同设备或标签修改不同实例、笔记或独立布局字段时，三方合并可保留不冲突的编辑。同一实验条件、同一正文或位置，以及删除与修改发生冲突时，不使用时间戳静默覆盖。可以采用服务器版本、保留本地为新工作台，或先导出保留内容。希望以保留的本地内容解决冲突时，选择“提交本地版本”并检查确认弹窗；确认提交使用当时最新的本地工作台和已经读取的最新服务器版本，提交失败保留弹窗与内容供重试。服务器已删除的文档不提供这个覆盖入口，必须明确恢复，旧队列不能使其自动复活。

账号切换会隔离命名空间、停止旧作用域的同步与运行资源，并拒绝迟到响应写入新账号。个人工作台属于实际账号和租户；管理员不会因此获得其他账号的个人画布访问权。匿名本机草稿也不会被当成另一个账号的文档。需要跨账号转移本人拥有的内容时，可在目标账号导入完整导出文件。

重新打开工作台会恢复布局、视口、场景、电路连接、原题、笔记、快照、比较、编辑历史和时间游标；实验默认暂停，不能因刷新自动启动后台运行。

## 维护与构建路径

源码真源是根领域包与 Harness overlay，实际编译和测试使用应用 overlay 后的 vendor 路径。

| 范围 | 路径和职责 |
| --- | --- |
| 共享数据协议 | `packages/physics-workbench`：纯 JSON 协议、校验、身份重建、合并和 CSV |
| 完整场景协议、物理引擎 | `packages/physics-scene`、`packages/physics-runtime` 及领域包 |
| 画布控制器和呈现 | `overlays/harness/files/packages/client/ui-physicsos/src/client/canvas` |
| 独立实验运行和既有视图 | 同插件的 `src/client/physics` |
| 账号私有服务与对象存储 | `overlays/harness/files/packages/physicsos/learning-host` |
| 实际 Harness 编译树 | `vendor/deepseek-harness`，由 `scripts/overlay/harness-overlay.mjs apply` 叠加 |

画布由 apply 生命周期的一份控制器持有实例注册表。节点通过稳定 owner key 和框架 Factory 读取实例摘要与帧；React Flow 节点数据仅含工作台和节点身份。`optional-canvas.js` 负责画布呈现，`optional-workspace.js` 复用实验运行和编辑；首页注册不导入另一份 React 或重量物理实现。

笔记正文、格式、修订、错误和待保存任务由控制器按账号命名空间、工作台和节点身份持有；组件只投影状态和是否展开编辑。停笔保存、离开页面、手工重试和导出使用同一条真实持久化路径，成功只覆盖本次已保存修订，保留期间继续输入的较新正文。账号切换后，旧身份键不能重新解析到新账号的同名文档。

浏览器依赖为 `@xyflow/react@12.12.1`（MIT）和 `idb@8.0.4`（ISC），精确版本在插件开发依赖和锁文件中，许可证见 [NOTICE.md](../NOTICE.md)。依赖变更必须同时更新两套工作区锁文件与许可说明。

构建、测试、备份和部署以服务器 `107.151.246.59` 的 `/opt/physicsos` 与 Docker 容器为准。本机用于源码编辑与 Git 整合，不因缺少本机 Docker 或依赖而判断服务器不可用，也不为部署另装本机环境。

服务器专用 builder 中先应用 overlay，再使用根 `package.json` 的校验与构建入口：

```sh
node scripts/overlay/harness-overlay.mjs apply
pnpm run verify:overlay
pnpm run verify:dependencies
pnpm run typecheck
pnpm run lint
pnpm run test
pnpm run build:web
```

`Dockerfile` 的 builder 使用 Node 24 和各工作区锁定的 pnpm，负责依赖、原生运行依赖、Harness lib、Host bundle、客户端 optional bundle、Web 构建以及最终入口与签名流程。增量验证可以在隔离 builder 中针对相关包执行，但 runtime 镜像里仅能运行 Node/Vitest 不等于完成发布构建。PostgreSQL 合同需要独立测试数据库；自跳过不得记为通过。候选浏览器验收必须使用隔离账号、数据库和 `app_data`，不能把默认验收脚本直接指向生产写入。

发布前重新核对远端 `main`、服务器源码检出和实际运行镜像的 revision，保留已上线的后续功能与修复。候选的菜单、专注编辑、真实器材手势、触屏、不同缩放倍率、明暗主题、窄屏、刷新和候选重启恢复均需留下实际验收证据。代码或局部测试通过不能替代这一步。

## 服务器数据备份与恢复

账号工作台使用独立 `physicsos_canvas` 元数据 unit，原学习记录仍使用 `physicsos_learning`。完整 Canvas REST、并发、配额与持久化协议见 [learning-host README](../overlays/harness/files/packages/physicsos/learning-host/README.md)。

不可变文件位于 `<DSH_HOME>/physicsos/canvases/v1/accounts/<owner-hash>/documents/<document-hash>`。生产 `DSH_HOME=/var/lib/physicsos` 由 Compose 的 `app_data` 卷承载。完整条件、快照、原始数据、布局历史及服务器复验证据既包含元数据引用，也包含这些私有文件，因此数据库与 `app_data` 必须在同一恢复点一起备份。PostgreSQL 单独备份不构成完整恢复集。

切换前保留旧镜像身份、数据恢复点和既有密钥文件。现有 `scripts/deploy/backup-full.mjs` 与 `restore-full.mjs` 的完整备份、加密、隔离恢复和验证流程见 [恢复演练说明](restore-drill.md)。密钥、Cookie 和完整环境变量继续通过既有文件或容器挂载使用，不进入聊天、日志或版本库；备份解密密钥另行保护。

对象发布要求受支持的 Linux/POSIX 文件系统、所有者权限、完整字节与摘要校验、文件及目录 fsync。缺失或损坏的引用对象返回真实错误，不生成空白替代内容。`canvasLimits` 配置请求、单对象、文档、账号、引用、历史、CSV 和服务器复算资源限额；达到限制时拒绝并提示，不能通过截断数据释放配额。

正式切换和回滚在服务器完成。恢复时使用独立恢复项目和卷验证数据库、私有文件、账号工作台读取及证据引用后，再按发布流程决定切换；不得复用生产卷做候选恢复实验，也不得清理其他会话的容器、镜像、数据卷或缓存。
